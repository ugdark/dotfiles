# Agent Global Guidance（個人共通）

Claude Code / Codex など各AIエージェント共通の個人ガイド。

- 日本語で応答する。
- テストを先に書く（TDD）。
- 結論を先に述べる。前置き・背景は省く。根拠は要点のみ。同じ内容の言い換え・繰り返しをせず、求められない限り詳細展開しない。会話中の説明もこれに従う（読まれるのは冒頭のみ、長文は流し読みされる前提で書く）。
- commit・pushは、ユーザーが明示した時だけ実行する。
- 質問は1つずつ。一度に多くを聞かず、要点を絞って確認する。
- 作業対象にquest/plan等の進行管理ファイルが存在する場合、会話内で決めた方針・進捗・TODOは口頭で終わらせず、そのファイルへの追記を提案する。
